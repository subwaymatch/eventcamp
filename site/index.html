Eventcamp

Three free website templates for events and conferences. Pick a theme, edit the HTML, put it on a server — there is no build step and nothing to install. Every card below is the template itself, running.

  • MIT licensed
  • No dependencies

What you get

  • One self-contained folder per theme: HTML, CSS, JavaScript, fonts and images, ready to copy onto any static host.
  • Semantic HTML with a skip link, visible focus states, keyboard navigation and a form built on native constraint validation.
  • Self-hosted fonts and an OpenStreetMap embed, so a page makes no request to a tracker or a CDN.
  • A theme is a short list of CSS custom properties — the rest of the stylesheet is identical across all three.
